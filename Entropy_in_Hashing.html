Entropy in Hashing

Understanding unpredictability, SHA-1 output length, and the difference between entropy and the avalanche effect.

Entropy measures how unpredictable or uncertain a value is. In cryptography, it helps describe how hard it may be for an attacker to guess an input. Entropy describes a source of inputs—not the visual complexity of a hash string.

1. Understanding Entropy

A string's entropy depends on how it was generated and what an attacker knows about the process, not just how complicated it looks.

2. Measuring Entropy

Entropy is measured in bits. For a uniformly random source with N equally likely outcomes:

When outcomes have different probabilities, Shannon entropy is defined as:

H(X) = − ∑x P(x) log2 P(x)

For resistance to guessing, the probability of the most likely candidate is particularly important. Min-entropy is defined as H∞(X) = −log2(maxx P(x)).

3. Entropy and SHA-1

SHA-1 always produces a 160-bit digest, regardless of input length. A 160-bit output does not imply the input had 160 bits of entropy.

Both inputs produce 160-bit hash values, but their original unpredictability can be very different.

Suppose an attacker knows a secret was selected uniformly from only 220 possible passwords. Even though SHA1(password) is 160 bits long, the attacker can test that small input space: hashing does not create entropy.

Important: Hash length, input entropy, preimage resistance, and collision resistance are different security properties. In particular, SHA-1 no longer provides acceptable collision resistance for modern security applications.

4. Entropy vs. the Avalanche Effect

These concepts answer different questions:

  • Entropy: How unpredictable is the input before we see it?
  • Avalanche effect: Does a tiny input change cause many output bits to change?

For example, changing the capitalization of one letter produces substantially different SHA-1 digests:

SHA1("hello") = aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d SHA1("Hello") = f7ff9e8b7bb2e09b70935a5d785e0cc5d9d0abf0

These different outputs illustrate the avalanche effect; they do not establish that either input has high entropy.

5. Why Entropy Matters in Cybersecurity

  • Passwords: Predictable passwords remain easy to guess after hashing. Use a dedicated password-hashing algorithm such as Argon2id with appropriate parameters and a unique salt.
  • Encryption keys: Keys require an unpredictable, cryptographically secure source of randomness.
  • Authentication tokens: Token unpredictability prevents attackers from guessing active credentials.
  • Salts: Unique, randomly generated salts prevent identical passwords from yielding the same stored verifier and impede precomputed attacks; salts do not need to be secret and do not add entropy to the password itself.
