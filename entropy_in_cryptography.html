Entropy in Information Theory and Cryptography

Entropy is a measure of uncertainty, randomness, or unpredictability. Its precise meaning depends on the field, including information theory, cryptography, and thermodynamics.

In cryptography, entropy describes how difficult it is for an attacker to predict a secret value, such as a password, encryption key, or random number.

1. Entropy in Information Theory

Claude Shannon introduced information entropy as a mathematical measure of uncertainty:

H(X) = −∑i=1n pi log2(pi)
  • H(X): Entropy measured in bits.
  • pi: Probability of outcome i.
  • n: Number of possible outcomes.

Higher entropy means greater uncertainty about the outcome.

Example 1: Flipping a fair coin

A fair coin has two equally likely outcomes: Heads, P(H) = 0.5; Tails, P(T) = 0.5.

H(X) = −[0.5 log2(0.5) + 0.5 log2(0.5)]
H(X) = 1 bit

A fair coin flip produces one bit of entropy.

Example 2: Flipping a biased coin

Suppose Heads has probability 0.9 and Tails has probability 0.1.

H(X) = −[0.9 log2(0.9) + 0.1 log2(0.1)]
H(X) ≈ 0.469 bits

The biased coin has less entropy because its outcome is more predictable.

Entropy reaches its maximum when Heads and Tails are equally likely.

2. Entropy in Cryptography

Cryptographic security depends heavily on unpredictable values, including:

  • Encryption keys
  • Nonces
  • Initialization vectors (IVs), when unpredictability is required
  • Passwords
  • Session secrets
  • Random seeds

If each of the 2128 possible 128-bit keys is equally likely, then:

H(K) = log2(2128) = 128 bits
2128 ≈ 3.4 × 1038 possible keys

A 128-bit value does not necessarily contain 128 bits of entropy. For example, a 128-bit string that is always all zeros has zero entropy.

3. Password Entropy

Assume each character is independently and uniformly selected from an allowed alphabet.

Eight lowercase letters

N = 268
H = log2(268) = 8 log2(26)
H ≈ 37.6 bits

Twelve printable ASCII characters

H = 12 log2(94)
H ≈ 78.7 bits

These estimates apply to truly random character choices. Human-selected passwords usually contain less entropy because of predictable words and patterns.

4. Shannon Entropy vs. Min-Entropy

Shannon entropy measures average uncertainty:

H(X) = −∑ pi log2(pi)

Min-entropy focuses on the probability of the most likely outcome:

H∞(X) = −log2(maxi pi)

For a coin that lands Heads with probability 0.9:

H∞(X) = −log2(0.9) ≈ 0.152 bits

Min-entropy is useful when evaluating an attacker's best single guess and in assessing cryptographic random-number generation.

5. Why Entropy Matters in Cryptography

Method A: Secure random generation

A cryptographically secure random number generator produces a uniformly distributed 256-bit AES key.

H(K) = 256 bits

Method B: Predictable generation

A program derives a 256-bit key from a timestamp with only one million possible values.

H(K) ≤ log2(1,000,000) ≈ 19.93 bits

An attacker could potentially test all one million possible seeds.

Important: Key length is not the same as key entropy.

6. Entropy and Cryptographic Hash Functions

SHA-256 always returns a 256-bit digest. However, hashing cannot increase the Shannon entropy of a deterministic input:

Y = SHA256(X)
H(Y) ≤ H(X)

If X has 20 bits of entropy, SHA-256(X) cannot contain more than 20 bits of Shannon entropy, despite its 256-bit output.

This matters in password hashing, key derivation, and random-number generation. Hashing can redistribute existing uncertainty, but cannot create new uncertainty from a deterministic input.

Key Takeaways

  1. Entropy measures uncertainty or unpredictability.
  2. In information theory and cryptography, entropy is measured in bits.
  3. Uniform distributions maximize entropy for a fixed number of possible outcomes.
  4. A long password or encryption key does not necessarily have high entropy.
  5. Deterministic hashing cannot add entropy to an input.
  6. Min-entropy is useful when evaluating the best single-guess probability.

Core principle: Random-looking data is not necessarily unpredictable data. Cryptographic systems need sufficient entropy in their underlying secrets, not merely outputs that appear random.
